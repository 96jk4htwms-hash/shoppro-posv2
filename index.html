เข้าสู่ระบบร้านค้า (เจ้าของร้าน)

กรอก 2 ช่องข้างล่างนี้เฉพาะตอน "สมัคร (ครั้งแรก)" เท่านั้น — ใช้ตั้งค่าบัญชีเจ้าของร้านคนแรกของร้าน (PIN นี้จะใช้ล็อกอินหน้าขายด้วย)

📥 ยกยอด & นำเข้าไฟล์ (สินค้า)

นำเข้าสินค้าจากไฟล์ Excel (.xlsx) 18 คอลัมน์: ชื่อสินค้า / SKU / ขนาด / หมวดหมู่ย่อย / ราคาทุน / ราคาขาย / ยอดยกมา / ไฟล์รูปภาพ / บาร์โค้ด / รหัสหมวดหมู่ย่อย / กลุ่มสินค้า / รหัสสินค้าหลัก / หมวดหมู่หลัก / รหัสหมวดหมู่หลัก / รุ่นย่อย(สี-ยี่ห้อ) / ชื่อหน่วยแบ่งขาย / อัตราส่วนหน่วยแบ่งขาย / ราคาขายหน่วยย่อย — แถวที่ไม่ได้กรอก SKU หรือบาร์โค้ดมา ระบบจะสุ่มให้อัตโนมัติ (บาร์โค้ดเป็นรูปแบบ EAN-13 ใช้กับเครื่องพิมพ์/สแกนบาร์โค้ดทั่วไปได้จริง) และจะจัดเข้าหมวดหมู่ย่อยใต้หมวดหมู่หลักให้อัตโนมัติ (สร้างหมวดใหม่ให้เองถ้ายังไม่มี) แถวที่ไม่ได้กรอกหมวดหมู่มาจะเข้าหมวดเริ่มต้น "หมวดหมู่(สินค้าใหม่)" — สินค้า 1 รายการอยู่ได้หลายหมวดหมู่ (ในช่องหมวดหมู่ย่อยใส่หลายหมวดคั่นด้วย ; หรือ | ) — แถวที่ราคาทุนสูงกว่า/เท่ากับราคาขาย ระบบจะตั้งทุนเป็น 30% ของราคาขายให้ — คอลัมน์ "รุ่นย่อย" ใช้เมื่อสินค้ากลุ่มเดียวกันมีหลายสี/ยี่ห้อ (แต่ละรุ่นย่อยควรมีไฟล์รูปเป็นของตัวเอง แอปจะแสดงเป็นการ์ดรูปให้เลือกอัตโนมัติ) และคอลัมน์หน่วยแบ่งขาย (ชื่อ/อัตราส่วน/ราคา) ใช้เมื่อสินค้านั้นแบ่งขายเป็นหน่วยย่อยได้ — ทั้งสองกลุ่มนี้เว้นว่างได้ถ้าไม่มี

🖼️ นำเข้ารูป (ชุด)

จับคู่รูปภาพเข้ากับสินค้าที่นำเข้าไว้แล้ว (จับคู่จาก "ชื่อสินค้า" ให้ตรงกับที่นำเข้าไว้ก่อนหน้านี้ และจับคู่ไฟล์จากรหัส P00001 หน้าชื่อไฟล์ได้แม้ชื่อไทยเพี้ยนตอนแตก zip) — ต้องเชื่อมต่อ + เข้าสู่ระบบ Supabase ก่อน เพราะรูปจะถูกอัปโหลดขึ้น Supabase Storage โดยตรง (ไฟล์รูปหลายพันไฟล์เก็บเป็น base64 ในเครื่องอย่างเดียวจะทำให้พื้นที่เก็บข้อมูลของเบราว์เซอร์เต็มและแอปพังได้)
